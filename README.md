# ROBO BOX

## Онлайн (Render)
GitHub → Render, HTTPS уже есть. Базу (Supabase) см. schema.sql и переменные SUPABASE_URL, SUPABASE_SERVICE_KEY.

## Без интернета (локально, телефоны по Wi-Fi/хот-споту)
Один раз, пока есть интернет: `npm install`, `npm run vendor` (скачает библиотеки и модель, ~35 МБ), `npm run cert` (нужен openssl, он есть в Git for Windows).
Дальше интернет не нужен:
1. Создайте сеть без интернета: включите раздачу Wi-Fi (хот-спот) на одном телефоне или на компьютере; к ней подключаются компьютер и оба телефона.
2. На компьютере `npm start`. В консоли будет адрес вида https://192.168.x.x:3000/.
3. Откройте этот адрес на большом экране (не localhost!), нажмите «Начать бой» → «Телефоны с камерой», отсканируйте QR. На телефонах примите предупреждение о сертификате («Дополнительно → Продолжить»).
Bluetooth-модем (раздача по Bluetooth) подходит только для одного телефона, для двух нужна Wi-Fi сеть.

## 4 телефона
- 2 телефона-камеры (QR слева в лобби): задняя камера, кнопки 🔍 (зум) и 🔄 (смена камеры) на телефоне. Ставьте телефон в 5–7 м от игрока, виден весь рост.
- 2 телефона-VR (QR справа, необязательно): откройте QR, нажмите «Надеть очки», вставьте телефон в VR-очки. Вид глазами робота, двойное касание — центрировать взгляд. Нужен гироскоп; на iPhone будет запрос разрешения.
- Роботы ходят по всему рингу (шаги вперёд/назад и вбок). Минимальная дистанция между роботами — 1 м.
